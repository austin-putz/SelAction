# Correspondence

Write-ups prepared for people outside the day-to-day work on this repository
(original authors, collaborators). One directory per piece, named
`YYYY-MM-<recipients>/`, holding the LaTeX source, the rendered PDF that was
sent, and the figure sources.

* `2026-10-bijma-dekkers/` - open modelling questions for Piter Bijma and
  Jack Dekkers: background, equations, numerical evidence and
  recommendations (`SelAction_open_questions.pdf`), sent 2026-10-05. It
  also asks for worked examples with known answers.
  It cites `fortran_mac/` at commit `dbdd69f`; that directory was renamed
  `fortran/` after it was sent (same code).

## Building

Figures are hand-written SVG generated by a script (same house style as
`docs/`), converted to PDF with `rsvg-convert`:

    cd correspondence/2026-10-bijma-dekkers
    python3 figures_src/make_figs.py .
    for f in fig_*.svg; do rsvg-convert -f pdf -o ${f%.svg}.pdf $f; done
    pdflatex SelAction_open_questions.tex && pdflatex SelAction_open_questions.tex
